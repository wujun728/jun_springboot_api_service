# 条件表达式可视化配置组件 (ConditionBuilder)

## 概述

`ConditionBuilder` 组件提供了一个可视化的界面来配置工作流条件分支的条件表达式，替代了原来直接输入表达式字符串的方式。

## 功能特性

### 1. 可视化配置
- **左侧变量选择**：从流程变量列表中选择要比较的变量
- **中间运算符选择**：根据变量类型自动筛选可用的运算符
- **右侧值配置**：支持静态值输入或选择其他流程变量进行比较

### 2. 智能类型适配

#### 根据左侧变量类型，自动提供合适的输入方式：

| 变量类型 | 可用运算符 | 静态值输入方式 |
|---------|-----------|---------------|
| string (字符串) | ==, != | 文本输入框 |
| number/double/long (数字) | ==, !=, >, <, >=, <= | 数字输入框 |
| boolean (布尔值) | ==, != | 开关选择器 |
| date (日期) | ==, !=, >, <, >=, <= | 日期时间选择器 |

### 3. 双向绑定

组件支持表达式的双向绑定：
- **解析**：将现有的表达式字符串解析为可视化配置
- **生成**：将可视化配置实时生成表达式字符串

## 使用示例

### 基本用法

```vue
<template>
  <ConditionBuilder
    v-model="conditionExpression"
    :process-variables="processVariables"
  />
</template>

<script setup>
import { ref } from 'vue'
import ConditionBuilder from './ConditionBuilder.vue'

const conditionExpression = ref("${field_input_8cnzsteaq = '李四'}")

const processVariables = ref([
  { name: 'field_input_8cnzsteaq', label: '姓名', type: 'string' },
  { name: 'field_amount', label: '金额', type: 'number' },
  { name: 'field_approved', label: '是否通过', type: 'boolean' }
])
</script>
```

### 在流程设计器中的使用

组件已集成到流程设计器的以下位置：

1. **条件分支节点配置**：选中条件分支节点时，在"输出连接配置"部分
2. **连接线属性配置**：单独选中连接线时，在"条件表达式"部分

## 配置步骤

### 步骤1：选择左侧变量
从下拉列表中选择要比较的流程变量，如"姓名"、"金额"等。

### 步骤2：选择运算符
根据变量类型，选择合适的运算符：
- 字符串：等于(==)、不等于(!=)
- 数字：等于(==)、不等于(!=)、大于(>)、小于(<)、大于等于(>=)、小于等于(<=)
- 布尔值：等于(==)、不等于(!=)
- 日期：等于(==)、不等于(!=)、大于(>)、小于(<)、大于等于(>=)、小于等于(<=)

### 步骤3：选择右侧值类型
- **静态值**：直接输入固定的值（如"李四"、1000、true等）
- **变量**：选择另一个流程变量进行动态比较

### 步骤4：输入/选择右侧值
根据选择的值类型：
- 静态值：根据左侧变量类型，使用对应的输入组件输入值
- 变量：从下拉列表中选择要比较的另一个变量

## 表达式示例

### 字符串比较
```
配置: 姓名 == '李四'
生成: ${field_input_8cnzsteaq == '李四'}
```

### 数字比较
```
配置: 金额 > 10000
生成: ${field_amount > 10000}
```

### 布尔值比较
```
配置: 是否通过 == true
生成: ${field_approved == true}
```

### 变量间比较
```
配置: 申请金额 > 预算金额 (两个变量比较)
生成: ${field_apply_amount > field_budget_amount}
```

## 表达式预览

组件底部会实时显示生成的表达式预览，方便您确认配置是否正确。

## Props

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|-------|------|
| modelValue | string | '' | 条件表达式字符串，支持 v-model |
| processVariables | ProcessVariable[] | [] | 流程变量列表 |

## Events

| 事件名 | 参数 | 说明 |
|-------|------|------|
| update:modelValue | (value: string) | 表达式更新时触发 |

## 技术实现

### 表达式格式
生成的表达式遵循 SpEL (Spring Expression Language) 格式：
```
${变量名 运算符 值}
```

### 字符串值处理
- 字符串类型的静态值会自动添加单引号：`'值'`
- 数字、布尔值不添加引号
- 日期会转换为 ISO 字符串格式并添加引号

### 表达式解析
组件能够智能解析现有的表达式，提取出：
- 左侧变量名
- 运算符类型
- 右侧值类型（静态值或变量）
- 右侧值内容

## 注意事项

1. **变量名必须存在**：左侧和右侧选择的变量必须在流程变量列表中定义
2. **类型匹配**：建议比较的两个变量类型一致，避免类型转换问题
3. **表达式实时生成**：任何配置改变都会立即生成新的表达式
4. **保持向后兼容**：生成的表达式格式与原有后端逻辑完全兼容

## 与后端集成

后端条件评估逻辑(`evaluateCondition`方法)支持以下运算符：
- `==`：等值比较（字符串、数字、布尔值和日期）
- `!=`：不等值比较
- `>`, `<`, `>=`, `<=`：数值和日期的大小比较

前端统一使用 `==` 作为等值比较运算符，后端会正确解析和执行（也兼容解析 `=` 运算符的旧数据）。
